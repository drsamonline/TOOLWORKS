# Code of conduct

**Version** 1.0 · **Effective** 15 November 2026

---

## The short version

Be decent. Assume the other person is competent and busy. Attack the entry, not the person.
This repository is a list of tools; nobody's dignity should be at stake in a bug report about
a category name.

---

## What is expected

| Expected | Detail |
|---|---|
| Say what is wrong and where | "the id for *Case converter* does not match TTB's catalogue" beats "this is broken" |
| Credit the source | if a tool is missing, name the project it comes from |
| Accept a "no" | the maintainer decides what this index is; a rejected change is not a judgement of you |
| Keep it short | a clear sentence is worth more than a long argument |

## What is not acceptable

| Not acceptable | |
|---|---|
| Harassment, insults, or demeaning anyone | in any language |
| Personal attacks on the maintainer or other contributors | |
| Political or religious campaigning | this is a tool index |
| Posting someone's private information | |
| Using an issue to advertise | |

## Scope

This applies to issues, pull requests, discussions and any other space attached to this
repository. It does not reach into anyone's private life.

## Enforcement

| Step | What happens |
|---|---|
| First | a request to stop, in the thread, with the reason |
| Second | the comment is removed and the thread is locked |
| Repeated or serious | the account is blocked from the repository |

Report a problem to sohilmomin2000@gmail.com with the subject `Toolworks conduct`. Reports
are read by the maintainer alone. There is no committee and no appeals process: the repository
is one person's, and pretending otherwise would be theatre.
